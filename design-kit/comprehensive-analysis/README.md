# Комплексный анализ закупки для Tender AI

Версия 1 от 19 октября 2026 года. Комплект для передачи Claude Code в актуальный репозиторий платформы.

Передайте весь архив и следующую команду:

> Прочитай CLAUDE_CODE_TASK.md. Реализуй в существующем Tender AI комплексный доказательный анализ закупки и единый отчёт по этому заданию. Используй AUDIT_REFERENCE.md как разбор ошибок образца, REPORT_TEMPLATE.md как структуру результата, context как ранее согласованные требования. Сначала обследуй текущий код и сохрани работающие функции. Затем внеси изменения, выполни тесты и покажи результат. Не ограничивайся новым текстом промпта.

## Состав

| Файл | Назначение |
|---|---|
| CLAUDE_CODE_TASK.md | Основное задание на внедрение и критерии приёмки |
| AUDIT_REFERENCE.md | Полный разбор девяти разделов присланного документа |
| LEGAL_SOURCES.md | Проверенные источники, границы проверки и правила актуальности |
| REPORT_TEMPLATE.md | Структура отчёта, одинаковая для экрана и экспорта |
| prompts/*.md | Промпты для извлечения, сопоставления, проверки и объяснения |
| reference/report.schema.json | Минимальный контракт отчёта, JSON Schema |
| reference/report-gates.cjs | Пример вычисления статусов без юридических констант |
| reference/report-gates.test.cjs | Исполняемые проверки защитных условий |
| examples/report-0342100024526000062.json | Пример честного результата при наличии только вторичного отчёта |
| examples/source-analysis-0342100024526000062.docx | Исходный отчёт другой программы, без изменений |
| examples/source-metadata.json | Идентификация разобранного DOCX |
| context/*.md | Предыдущие задания по чтению, заявке и калькулятору |
| VALIDATION.md | Что проверено в этом комплекте и что должен проверить Claude |

Это готовая спецификация внедрения с вспомогательным кодом. Она не означает, что сервер уже изменён. Код из reference не заменяет извлечение документов, юридический движок, финансовый модуль и проверку доступа. Его входы формируются сервером после проверки доказательств; принимать их флагами от браузера нельзя.

Присланный DOCX — аналитический отчёт другой программы. Оригиналы извещения, проекта контракта и приложений не получены. Поэтому пример не выдаёт сведения из него за подтверждённую документацию и не рекомендует участие до проверки существенных условий.

Для запуска локальных проверок примера: `node --test reference/report-gates.test.cjs` из папки комплекта. Для проверки JSON Schema нужен доступный в среде валидатор Draft 2020-12; зависимости текущего проекта менять только после обследования.
