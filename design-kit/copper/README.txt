Передайте Claude Code весь архив, а не только картинку.
Распакуйте его рядом с актуальным проектом либо в папку design-handoff проекта.

Сообщение для Claude Code:

Прочитай CLAUDE_CODE_TASK.md из комплекта tender-ai-copper-kit и посмотри
reference/tender-ai-copper-approved.png. Владелец утвердил вариант «Медь».
Внедри этот дизайн в текущую платформу, используя assets/tender-copper-hero.png.
Сохрани действующие функции, маршруты, данные и расчёты. Выполни проверки
из задания и покажи скриншоты реализованного интерфейса. Не ограничивайся планом.

В архиве:
- CLAUDE_CODE_TASK.md — подробное задание;
- reference/tender-ai-copper-approved.png — утверждённый макет;
- assets/tender-copper-hero.png — отдельная подложка без надписей;
- reference/copper.tokens.css — исходные токены для интеграции;
- ASSETS.json — размеры и контрольные суммы изображений.

Это комплект для внедрения через Claude Code. Изменения рабочего сервера
самим архивом не выполняются. Макет содержит демонстрационные данные.
