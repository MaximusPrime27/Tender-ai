## Примечания по источникам

- **ФЕЛИКС**: Есть отдельный раздел работы с тендерами и индивидуальными проектами; оптовая цена требует условий конкретного заказа.
- **ЮНИТЕКС**: Дилерский раздел и широкий офисный ассортимент; модели и предложения продавцов хранить отдельно.
- **RIVA / РВ Групп**: На сайте заявлена работа только с дилерами. Обивка, цвет и исполнение входят в идентичность варианта.
- **ДЭФО**: Есть корпоративный отдел и партнерская программа; роль изготовителя подтверждать для конкретной марки и SKU.
- **Славянская мебель**: Официальный сайт найден в поиске, прямое чтение завершилось таймаутом. Не считать подключенным парсером.
- **Фабрика им. Мебеля / fm18**: На сайте также есть учебная, дошкольная, гостиничная мебель и мебель для библиотек; отдельные условия для опта.
- **MEBELA**: Ассортимент найден в индексе; при открытии 502. Отложенный источник, условия опта не проверены.
- **CHAIRMAN / Тайпит**: Ссылка «Стать дилером» ведет на mebel.taipit.ru. PDF-инструкции бывают без текстового слоя; читать сноски обивок.
- **Бюрократ / MERLION**: На официальном сайте есть B2B MERLION, инструкции и техническая информация. Нагрузки моделей меняются: проверять версию.
- **МЕТТА**: Есть B2B-кабинет b2b.metta.ru. Обивка, механизмы и аксессуары одной серии могут различаться.
- **БюроКресла**: Отдельный продавец кресел Бюрократ; не считать второй фабрикой. Оптовые условия и реквизиты опубликованы на сайте.
- **ПРОМЕТ / ПРАКТИК**: Сохранить существующий id promet. ПРАКТИК — марка группы; safe.ru не добавлять как независимого от ПРОМЕТ изготовителя.
- **ПАКС-Металл**: paksmet.ru и paks-met.ru не смешивать: второй сайт заявляет дилерскую роль. Автоматическое чтение основного сайта вернуло 403.
- **ДиКом**: Производитель металлической мебели; доступность загрузки и оптовые условия требуют проверки коннектора.
- **Верстакофф**: Верстаки, шкафы, стеллажи, антистатическая мебель; есть конфигуратор. Конфигурацию сохранять как состав компонентов.
- **Феррум**: В документации отдельно доступны каталоги, прайсы, паспорта, сертификаты. Нагрузка на ящик, полку и верстак — разные поля.
- **Росметалл**: Подробные карточки учебной мебели с ростовыми группами. Параметры разных вариантов нельзя объединять.
- **Альтком-Мебель**: Есть дилерская программа и подбор комплектации учреждения. Точные материалы и исполнения подтверждать карточкой/спецификацией.
- **ФМК АГАТ**: Оснащение школ и детских садов, типовые и проектные решения. Сайт также ссылается на agatmk.ru; не создавать дубль фабрики автоматически.
- **ЛАМИФОР**: Прямо заявлена оптовая поставка школьной мебели. Рост, регулировки и пластик столешниц проверять по варианту.
- **PELIZMA**: Первичный сайт найден в индексе; прямое чтение — таймаут. Заявления о реестрах не подтверждают включение любого SKU.
- **ПартаСтул**: Серийные парты, стулья, лабораторные столы; сайт предлагает спецусловия при крупных партиях. Условия конкретного КП неизвестны.
- **АСК / tdask**: Текстовое чтение возвращает только Loading/JavaScript. Не смешивать с prom-ask.ru без подтверждения юридической связи.
- **MET / met-company**: Медицинские и функциональные кровати. met.ru учитывать как возможный связанный канал после проверки, не как независимый завод.

- **Хоббика**: Садово-парковая мебель; сайт найден, чтение завершилось таймаутом. Монтаж и основание проверять отдельно.

- **Самсон-опт**: Сохранить старый id samson. Партнерский каталог и цены могут требовать разрешенного доступа; наличие публичного API не подтверждено.
- **Сима-ленд**: Сохранить id sima. Оптовые цены зависят от маркировки и заказа; текстовое открытие страницы условий завершилось таймаутом.
- **Комус-ОПТ / Комус**: Сохранить id komusopt. Оптовый и розничный канал одной группы хранить раздельными предложениями; цены и наличие зависят от региона.

## Что еще проверить на платформе

Доступность с IP сервера, robots и условия чтения, наличие выгрузки по договоренности, точное юрлицо, регион доставки, минимальную партию, срок изготовления, НДС, сборку, подъем и монтаж. Эти значения оставлены неизвестными, а не заполнены предположениями. Публичное чтение проверено через исследовательский веб-инструмент; это не проверка промышленного коннектора. Условия по API и массовой загрузке ни для одного источника не считаются подтвержденными.
