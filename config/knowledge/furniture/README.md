# Пакет мебели для Quod

Начать с `QUOD_TASK.md`. Пакет дополняет текущую платформу; установщик старого поиска не требуется.

| Файл | Назначение |
|---|---|
| `config/furniture-suppliers.json` | 42 источника поставщиков, 8 каналов и маршруты 16 профилей |
| `SUPPLIERS.md` | Читаемый список, ссылки, доступность и особенности источников |
| `config/furniture-profiles.json` | Подсказки извлечения требований по типам мебели, без ограничения числа полей |
| `config/furniture-aliases.json` | Синонимы и запрещенные смысловые подмены |
| `config/search-policy.json` | Бесплатный поиск в рамках текущих провайдеров, дочитывание, кэш, очередь продолжения |
| `contracts/requirement-and-evidence.example.json` | Пример связи требования, исполнения, источника и решения; содержит явные демонстрационные значения |
| `tests/acceptance-cases.json` | Сценарии приемки для действующего парсера и поиска |
| `tools/check-contract-results.mjs` | Проверка результатов адаптера платформы по ожидаемым выходам |
| `research/live-pilot.json`, `RESEARCH.md` | Результаты чтения реальных карточек и PDF, ограничения исследования |
| `tools/validate-kit.mjs` | Локальная проверка ссылочной целостности и структуры пакета |

Команды выполнять из корня распакованного пакета:

```bash
node tools/validate-kit.mjs
node tools/check-contract-results.mjs /absolute/path/actual-results.json
```

Первый скрипт проверяет данные пакета. Второй требует результатов реального запуска на платформе, сам поиск не выполняет. Рабочий сервер и актуальный код Quod в исследовании не были доступны. Фактическое мебельное ТЗ пользователя не предоставлено, поэтому 100% соответствие реальной закупке здесь не установлено.

Регистрация у поставщиков, отправка запросов, оплата сервисов, публикация и развертывание этим пакетом не выполняются.
