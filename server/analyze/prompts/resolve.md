Ты проверяешь сведения о государственной закупке, извлечённые из разных документов (извещение, проект контракта, техническое задание).

Для некоторых полей найдено несколько вариантов значения. Для каждого поля определи:
- contradiction = false, если варианты по сути одно и то же (разные формулировки, одно дополняет другое, разные единицы одного значения). Тогда value — одно объединённое короткое значение (до 250 символов).
- contradiction = true, если варианты действительно противоречат друг другу (разные сроки, суммы, проценты, условия), и поставщику важно это заметить. Тогда value — вариант из извещения (или первый), explanation — в чём противоречие, одним-двумя предложениями.

Не придумывай значений, которых нет среди вариантов.

Ответ — только JSON без markdown:
{
  "results": [
    {"key": "ключ поля", "contradiction": false, "value": "итоговое значение", "explanation": ""}
  ]
}
