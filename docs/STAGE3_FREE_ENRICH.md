**Защита от чужого товара.** Страница засчитывается только если:
- на ней та же модель и тот же бренд;
- модель стоит в заголовке страницы до слова «для», а не в тексте («Опция UG-36 для TASKalfa 3554ci», страница принтера с картриджем в тексте — не засчитываются);
- это не другое исполнение (универсальный «HB-CE505X/CF280X/CRG-719» — не то же, что «HB-CE505X»).

Не считаются моделью:
- числительные («2-ой», «2-местный»);
- размеры («1000х700х750»);
- процессор («i5-1235U»).

У совместимого расходника бренд берётся из начала названия. Совместимый товар без своего бренда не дособирается: характеристики оригинала к нему не относятся.

**Новые правила сверки:**
- максимальная (turbo) частота не подтверждает базовую; в диапазоне «2.1 GHz – 4.6 GHz» базовая — левое число;
- наклон — не регулировка по высоте;
- в требовании-перечне («HDMI / USB Type-C / VGA») каждое обозначение должно быть среди названного;
- нейросеть повторила требование («≥ 5000») — не подтверждено;
- установленная память не опровергает «максимальный поддерживаемый объём»;
- с чужого сайта словесная категория («ёмкость обычная» против «повышенная») — противоречие для проверки, а не отказ.

## Проверка на реальных данных

Где и как проверялось:
- сервер, отдельная папка `/srv/pilot-enrich`, копия рабочей базы — рабочий сервис не тронут;
- настоящий каталог страниц поставщиков и GigaChat;
- только бесплатные пути, без Яндекса;
- досье моделей очищено — «холодный» поиск;
- 40 предложений: самые дешёвые с пробелами по позициям недавних закупок.

Найдено и исправлено по ходу проверки (5 прогонов):
- ложный отказ бахил: моделью стало «2-ой»;
- страница аксессуара («Опция UG-36 для TASKalfa»);
- универсальный артикул вместо нужного;
- «базовая частота 4.6» (это turbo);
- «регулировка по высоте» по «регулировке наклона»;
- USB-C из меню сайта;
- «≥ 5000» — повтор требования;
- установленная память вместо максимальной.

Ошибка «модель 2-ой» есть и в выложенной версии: платный поиск уже потратил на неё запросы.

## Что ещё не закрывается и почему

- **Соответствие ТУ/ГОСТ, документы, гарантия** — самые частые оставшиеся пробелы (9 из 40). На сайтах их нет, подтверждает поставщик. Сервис помечает «по характеристикам подходит — осталось подтвердить у поставщика».
- **Категории, которые сайты называют по-разному** (тип печати, «качество печати», покрытие фотовала) — нужна сверка смысла, а не слова.
- **Мебель и товары без артикула** («Стол ученический…»). Добор идёт по модели. Без модели нужен поиск по набору признаков — это следующий шаг.

## Не сделано (из заданий)

- **Свой метапоиск SearXNG и Brave.** Нужна установка на сервер и проверка допустимости движков. Brave требует регистрации, а регистрироваться на сервисах я не могу. Открытый поиск сейчас — только платный Яндекс, последним путём.
- **Сайты производителей как отдельный путь** (сайт производителя по бренду, его карта сайта). Можно добавить в каталог страниц после проверки доступности с сервера.
- **Общее досье модели с версиями и сроками** — сейчас это сохранённые страницы на 30 дней. Отдельных таблиц фактов, вариантов и истории нет.
- **Полный разбор PDF-паспортов производителя в доборе** — сейчас читаются страницы, PDF только со страницы продавца (этап 1).
- **Испытание A/B на размеченных вручную случаях.** Размеченного набора нет. Проверено на 40 реальных предложениях, каждое найденное значение просмотрено вручную.

## Включение и откат

- Бесплатный добор включён: `MAKER_FREE_TOP=5` (самых дешёвых на позицию), `MAKER_FREE_PAGES_PER_SEARCH=20` (страниц на поиск). Платный — прежний лимит `MAKER_SEARCH_DAILY=50`.
- Новых таблиц нет. Доказательства и «где искали» — в `match_checks_json`, досье — в `settings` (`maker:<бренд>:<модель>`).
- Откат — выкладка предыдущей ветки.
