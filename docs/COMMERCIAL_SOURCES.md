# Коммерческие закупки площадок (вне ЕИС)

Закупки по 44-ФЗ и 223-ФЗ сервис получает из ЕИС (ГосПлан и лента ЕИС): там они есть, на какой бы площадке ни шли. Коммерческие закупки компаний публикуются только на самой площадке. Для них — отдельные источники.

Источники включаются в `TENDER_SOURCES`, например:

```
TENDER_SOURCES=gosplan,eis-rss,roseltorg,etpgpb,fabrikant,sberast
```

| Источник | Что берёт | Как находит | Ограничения |
|---|---|---|---|
| `roseltorg` | Росэлторг: коммерческие закупки | страница поиска процедур | — |
| `etpgpb` | ЭТП ГПБ: «ЭТП Клик», «Торговый портал», корпоративные заказчики, «Закупки.Бизнес» | карта сайта, в адресе — название процедуры | robots.txt закрывает адреса с «?» и листание списка; документы (`/uploads/`) закрыты — их скачивают на площадке |
| `fabrikant` | Фабрикант: секция «Коммерческие процедуры» | поиск по слову (`/procedure/search/purchases?query=`) | «Фабрикант.Маркет» показывает закупки только скриптом — не читается; документы — после входа |
| `sberast` | Сбербанк-АСТ: коммерческие заказчики, Почта России, Транснефть, Центробанк, Сбербанк, АФК «Система», Росатом и 223-ФЗ без номера ЕИС | общий реестр процедур (тот же запрос, что делает страница `UnitedPurchaseList.html`) | секция «Ритейл» не берётся (robots.txt закрывает `/Retail`); страницы процедур и документы — после входа; позиции — только названия товаров |

## Как работает каждый источник

**ЭТП ГПБ** (`server/sources/etpgpb.js`):
1. Свежая часть карты сайта: части, обновлённые за 3 дня.
2. Отбор по словам направлений: латиницей, по основе слова. У длинных слов основа длиннее, у коротких («МФУ») слово должно стоять в адресе отдельно.
3. Пропускается продажа и аренда имущества.
4. Страницы процедур открываются с паузой `ETPGPB_DELAY_MS`, не больше `ETPGPB_MAX_PAGES` за обновление.
5. Со страницы берутся номер, название, цена, срок, заказчик с ИНН, адрес поставки и регион, перечень товаров.
6. Пропускаются закупки 223-ФЗ (11-значный номер извещения ЕИС), 44-ФЗ и завершённые.

**Фабрикант** (`server/sources/fabrikant.js`):
1. Поиск по каждому слову направления: не больше 15 слов, пауза `FABRIKANT_DELAY_MS`.
2. Из данных страницы поиска берутся только карточки секции `commercial`.
3. Страница процедуры: заказчик (или организатор) с ИНН, цена, срок, регион, ОКПД2, лоты в приёме заявок.

**Сбербанк-АСТ** (`server/sources/sberast.js`):
1. Запрос `POST https://www.sberbank-ast.ru/api/Processing/main` (окно `/EsOpenUnitedPurchaseList`) — им же пользуется открытая без входа страница реестра. robots.txt `www.sberbank-ast.ru` не задан.
2. Отбор по торговым секциям (`SECTIONS` в файле), по 100 закупок, новые сначала; пауза `SBERAST_DELAY_MS`, не больше `SBERAST_MAX_PAGES` страниц. Окно — с прошлого обновления, в первый раз 3 дня (около 1000 строк, из них больше половины — 223-ФЗ с номером ЕИС).
3. Пропускаются: номер ЕИС (11 или 19 цифр), анализ рынка, запросы информации, отборы, продажи и аренда, закрытый приём заявок.
4. Если название общее («Запрос предложений в электронной форме…»), к нему добавляются первые товары из перечня — по ним работают фильтры направлений.
5. Номер в сервисе: `SBAST-<номер процедуры>.<лот>`. Позиции после перезапуска сервера находятся поиском по номеру.
6. Пробный прогон 23.10.2026: за 3 дня 381 закупка вне ЕИС, 19 прошли фильтры профиля (серверы, МФУ, ноутбуки, периферия, кабели).

## Куда не ходим и почему (проверено 23.10.2026)

| Площадка | Причина |
|---|---|
| Сбербанк-АСТ, «Ритейл» | robots.txt `utp.sberbank-ast.ru` закрывает `/Retail` |
| SberB2B (sberb2b.ru) | отдельный сайт с потребностями компаний — не разбиралось |
| РТС-тендер | серверу отвечает 503 |
| ZakazRF, АСТ ГОЗ | серверу не отвечают |
| com.roseltorg.ru | robots.txt запрещает роботам весь сайт |
