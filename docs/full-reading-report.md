## На сохранённых разборах (локальная копия базы, 359 закупок)

Считалось по уже сохранённым текстам, без обращения к нейросети: `node scripts/reading-coverage-report.js --data <папка> --top 1000 --summary`.

- Прежнее чтение ТЗ видело не все страницы у 341 закупки из 359 (95%); меньше половины текста — у 326.
- У 170 закупок пропускались страницы, похожие на техническое задание.
- Прежнее извлечение позиций видело меньше половины текста у 324 закупок (90%).
- Шесть самых больших закупок: чтение ТЗ видело 3–5% текста (8–17 страниц из 198–334).
- Теперь на чтение ТЗ уходит в среднем 5,8 фрагмента на закупку (медиана 5, максимум 41) вместо одного запроса.
- В той же базе 291 рекомендация из 377 — «участвовать с оговорками».

Сравнить содержание разборов (число найденных позиций, условия) на живой нейросети не удалось: GigaChat отвечает `402 Payment Required` — пакет запросов закончился (на сервере — с 10.10.2026, 23:05).

## Как выглядит результат

- **Полный разбор**: «Получено вложений: 3 из 3; прочитано файлов: 3 из 3; обработано страниц PDF: 3 из 3; принято фрагментов: 1 из 1», рекомендация окончательная.
- **Неполный**: перечислены пропуски с действием; рекомендация «недостаточно данных» (предварительная); «не найдено» по условиям показывается как «неизвестно».
- **Требует проверки**: прочитано всё, но в документах противоречие или не подтверждена цитата существенного условия — рекомендация предварительная.
- **Повтор**: «Повторить непрочитанные части» (`POST /api/analyses/:id/retry`) дочитывает нераспознанные страницы и отправляет нейросети только несостоявшиеся или изменившиеся фрагменты.
- **Ручная проверка пробела**: галочка «проверено мной вручную» (`POST /api/analyses/:id/gaps`) — решение пересчитывается без нейросети.

## Кто читает документы: правила, Lite или Pro (11.10.2026)

Запас бесплатных токенов сильной модели (GigaChat-2-Max, 25 млн в год) закончился 10.10.2026: сервис израсходовал его за 20 дней. Проверено на шести настоящих закупках (23 фрагмента, тексты из сохранённых разборов; эталон позиций — извещение, эталон условий — прежний разбор моделью Max):

| Кто читает | Позиции найдены | Лишние позиции | Цитаты подтверждены | Ключевые условия совпали | Сбои |
|---|---|---|---|---|---|
| Правила по таблицам (без нейросети) | 32 из 33 (97%) | 0 | 100% — цитата берётся из строки таблицы | — (условия правила не читают) | — |
| GigaChat-2-Pro | 21 из 33 (64%) | 3 | 70% | 33 из 36 (92%) | 0 из 46 запросов |
| GigaChat-2 (Lite) | 15 из 33 (45%) | 6 | 53% | 28 из 36 (78%) | 6 из 46 (испорченный JSON), 20 повторов |

Оговорка: нейросети читали прежний текст документов, где таблицы Word были «расплющены»; правила — новый текст с сохранёнными строками таблиц. На восьми закупках (48 позиций) правила нашли 39 (81%): в двух закупках таблицы товаров в прочитанных файлах не было.

Что из этого следует и что сделано:
- **Позиции и требования ТЗ** читает «читатель по правилам» (`server/extract/tables.js`, `server/tenders/rule-items.js`): таблицы Word и Excel сохраняются построчно, из них берутся название, количество, единица и характеристики — с цитатой и страницей. Нейросеть подключается, только если таблицы с позициями нет.
- **Условия закупки, риски, резюме, правовая проверка** остаются на сильной модели — теперь Pro. Lite для извлечения условий не годится: теряет каждое пятое ключевое условие и в 13% запросов возвращает испорченный ответ.
- **Lite** по-прежнему оценивает ленту. Список задач облегчённой модели задаётся настройкой `GIGACHAT_LITE_TASKS`.

Проверка целиком на живой модели Pro (настоящие документы закупки постельных принадлежностей, 5 файлов): 80 секунд, 28 427 + 3 810 токенов; позиции — 3 из 3 по правилам, требований 6 / 8 / 6 — столько же, сколько раньше находила Max, все подтверждены цитатами; условий найдено 21 из 23. Прежний разбор той же закупки моделью Max — 18 676 + 2 447 токенов без учёта отдельного чтения ТЗ.

Повторить сравнение: `node scripts/reader-compare.js --data <папка> --tenders <id,…> --models GigaChat-2,GigaChat-2-Pro` (ответы сохраняются, повторный запуск токены не тратит).

## Ограничения

- Координаты внутри страницы PDF не сохраняются — только номер страницы. У Word — условные блоки текста, не страницы; у таблиц — лист и номера строк (без адресов ячеек).
- Таблицы внутри Word читаются как сплошной текст (строки не разделяются) — как и раньше.
- Качество распознавания не измеряется: распознанные страницы помечаются для сверки с оригиналом, процент качества не выдумывается.
- Страница PDF с рисунком и без распознанного текста остаётся «непрочитанной», пока человек не отметит её проверенной.
- Изображения внутри Word без распознанного текста (фото, схемы) показываются предупреждением и решение не блокируют.
- Признак завершения ответа у YandexGPT записан по памяти о его API и на живом ключе не проверен; у GigaChat — сверен с документацией (`stop`, `length`, `function_call`, `blacklist`, `error`).
- Разборы, сделанные раньше, отчёта о полноте не имеют и показываются как «прежняя версия, полнота неизвестна». Массовая переработка базы не запускалась.
- Расход токенов вырастет: ТЗ и позиции теперь читаются по всем фрагментам. Бюджеты одного прохода: `ANALYSIS_MAX_CHUNKS` (80), `SPEC_MAX_CHUNKS` (20), `ITEMS_MAX_CHUNKS` (20), `OCR_MAX_PAGES` (200).
