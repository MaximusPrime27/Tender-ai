# Пакет агентов tender-ai

Все агенты пишут в общий журнал (`server/agents/journal.js`):
- прогоны;
- уроки по коду ошибки **и площадке**;
- показатели по дням.

Так каждый агент учится на своих ошибках, а управляющий видит динамику.

У урока три источника:
- **сам** — агент поймал ошибку сам;
- **проверяющий** — ошибку нашёл другой агент;
- **человек** — поправка или отказ пользователя.

## Иерархия

```
Управляющий ─ расписание, лимиты, сбои, дневной отчёт в Telegram
 ├─ Наладчик ─ сам повторяет сорвавшееся по известной причине, неизлечимое — владельцу
 ├─ Знаток товара ─ карточки видов, учится на контрактах и ваших поправках, сам снимает заявки с другим товаром
 ├─ Проверяющий находки ─ фильтр перед Telegram, проверяет работу остальных
 ├─ Агент заявок ─ отбор закупок, сверка, расчёт выгоды
 │   ├─ Читатель документов ─ разбор документации правилами
 │   ├─ Разведчик базы товаров ─ товары и характеристики
 │   ├─ Разведчик поставщиков ─ новые оптовики в слабых нишах
 │   └─ Итоги торгов ─ кто выиграл и по какой цене
 ├─ Подготовка заявки ─ документы по образцу, проверка требований площадки
 └─ Итоговый пакет документов ─ доводит пакет до выгрузки; с 31.10 в автоматическом режиме
```

## Этапы

| Этап | Что делаем | Как учится | Статус |
|---|---|---|---|
| 1 | Журнал, **проверяющий находки**, **управляющий** с вечерним отчётом | проверяющий → уроки агенту заявок; ваш отказ от «верной» закупки → урок проверяющему | выложен 30.10.2026 |
| 2 | **Читатель документов** | сверка своих разборов с извещением ЕИС; копит, по каким площадкам и полям ошибается; опоры (слова перед верным значением) для закупок без извещения | выложен 30.10.2026: точность 50% → 63% |
| 3 | **Подготовка заявки** | что не готово в заявке по площадке и закону; новые требования на площадке; знак и страна из ваших прежних правок того же товара; проверяющий снимает «готово» при критичных замечаниях | выложен 30.10.2026 |
| 4 | **Разведчик поставщиков**, развитие **разведчика базы товаров** | какие сайты дают подходящий товар (→ свой каталог), пустые сайты (→ из каталога), слабые ниши (→ агенту поиска поставщиков) | выложен 30.10.2026 |
| 5 | **Итоги торгов** — отдельный агент | реальное снижение цены по нишам и заказчикам → точнее расчёт прибыли | выложен 30.10.2026 |
| 6 | **Итоговый пакет документов** — отдельный агент | пересборка при сбое, ваш прежний выбор документов участника, ошибки файлов по площадке и закону, исправленное; проверяющий сверяет «можно выгружать» с самим пакетом | выложен 30.10.2026 |
| 7 | **Наладчик**; автоматический режим итогового пакета; бесплатный добор по модели в агенте заявок; читатель: цена заказчика | повтор после отказа ЕИС, «нет ссылок», лимита поиска (до 3 раз); повторяющиеся ошибки без лечения — сообщение владельцу; читатель по ЕИС: цена заказчика 58% → 81% | 31.10.2026 |
| 8 | **Знаток товара**, таблица задач управляющего, проверка вида и назначения товара, цена против прошлых контрактов | контракты и выбор человека → свои слова вида; заменённый человеком товар и самопроверка → признаки ошибки; повтор ошибки трижды за неделю → задача с целью и сроком, проверка по числам | выложен 31.10.2026: медицина работает сразу, остальные ниши наблюдают |

## Кем работает каждый агент

| Агент | Какого человека заменяет | Чем измеряем | Цель |
|---|---|---|---|
| Управляющий | руководитель отдела | сколько задач закрыто в срок | все задачи закрыты или переданы владельцу |
| Проверяющий находки | старший специалист, проверяет за другими | пропущенные ошибки, ваши отказы от «верных» | 0 пропущенных |
| Агент заявок | специалист по тендерам | доля верных заявок среди выгодных | ни одной заявки с чужим товаром |
| Знаток товара | товаровед | чужих товаров среди подходящих, потеряно верных, повторы ошибок | потеряно 0, повторов 0 |
| Читатель документов | помощник, читающий документацию | сверка с извещением ЕИС | 90% полей верно |
| Разведчик базы товаров | контент-менеджер каталога | заполненность карточек | характеристики у всех карточек в работе |
| Разведчик поставщиков | закупщик | сколько сайтов дали подходящий товар | рост в слабых нишах |
| Итоги торгов | аналитик | ошибка прогноза снижения | меньше 5 пунктов |
| Подготовка заявки | оформитель заявок | заявок без замечаний | 100% |
| Итоговый пакет документов | оформитель пакета | пакетов, готовых к выгрузке | 100% без вашей правки |
| Наладчик | дежурный системный администратор | спасённых заявок среди разобранных | все сбои с известной причиной закрыты |

## Порядок запуска

Каждый этап проходит один цикл:
1. Тесты.
2. Выкладка с копией базы.
3. Сутки наблюдения по вечернему отчёту управляющего.
4. Разбор уроков.
5. Следующий этап.
