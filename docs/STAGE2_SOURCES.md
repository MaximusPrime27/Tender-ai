# Этап 2: источники по группам товаров

Задание: раздел 11 файла `design-kit/stage1-search/Tender_AI_Etap_1_Poisk_i_sverka_TZ.md`. Каждую из 73 групп каталога (`config/product-groups.json`) нужно связать с конкретными источниками и для каждого указать:
- опт или розница;
- API, прайс или открытая карточка;
- нужна ли регистрация;
- регион и доставка;
- насколько источник проверен.

При этом нельзя объявлять все каталоги готовыми автоматическими источниками.

Состояние: сделано локально 22.10.2026, на сервер **не выложено**.

## Как устроено

**Связь группы с сайтами — откуда берётся:**
1. **Списки поставщиков** (`config/stores.json`, `config/profile-suppliers.json`). Как поставщик привязан к группам:
   - поставщик ниши (направление `g-<группа>`) — прямо к своей группе;
   - поставщик основной ниши (computers, network, cctv, office) — к группам, чьи коды ОКПД2 пересекаются с кодами направления.
2. **B2B-каталоги** — по кодам.
3. **Проверено делом:** сайт дал цену по товарам группы со сверкой «соответствует» или «частично». Засчитывается при двух таких ценах или одной полностью соответствующей: одна «частичная» цена — часто случайность (аптека в «Инструменте»).

**Способ получить цену:**
- цена на сайте без входа;
- цена на сайте, страницы находим через Яндекс;
- API для партнёров;
- после регистрации юрлица;
- прайс;
- по запросу (КП);
- розница — только характеристики и ориентир цены.

**Уровень проверки:**
- проверено делом;
- каталог страниц собран;
- проверен сайт (при добавлении: открыт роботу, цена без входа);
- только в списке.

**Роли источника** (из задания, раздел 8E):
- найти товар;
- взять характеристики;
- взять закупочную цену;
- ориентир цены.

Розница больше не блокирует характеристики: поиск по модели открывает страницы розничных сетей с соблюдением robots.txt.

**Покрытие группы:**
- «хорошо» — не меньше трёх сайтов с открытыми ценами, и хотя бы один проверен делом или у двух собран каталог страниц;
- «мало» — сайты с ценами есть, но их мало или они не проверены; либо цены только по регистрации, прайсу, КП;
- «нет источников».

Для групп, где цены обычно не публикуют (продукты, топливо, растения, автомобили, станки), совет — КП местным поставщикам. В список «с чего начать подбор» такие группы не попадают.

**Профиль группы** (`config/group-sources.json`) — оценка рынка на 22.10.2026, не проверка. Экран так и подписан. Проверенным считается только то, что сервис видел сам.

Расход: никаких платных запросов. Таблица считается по уже собранным данным: обход всех позиций — около 4 секунд на копии базы, результат держится час.

## Не сделано

- **Подбор поставщиков для групп без источников** (≈ 20 групп, где цены публикуют). Способ проверен на нишах 19.10:
  - 2 запроса к Яндексу на группу (≈ 0,5 ₽ за запрос), затем проверка сайта с сервера: открыт роботу, цена без входа;
  - на все такие группы — около 40 запросов, ≈ 20 ₽.
  - Не запускалось: нужен ответ владельца.
- **Регион и доставка по каждому сайту** известны только у проверенных делом (регион продавца по ИНН). У остальных — «не указано», а не догадка.
- **Импорт прайс-листов** дистрибьюторов (цены после регистрации) — отдельная задача: нужны договоры и файлы.
